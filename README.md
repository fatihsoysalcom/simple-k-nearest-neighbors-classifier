# Simple K Nearest Neighbors Classifier

This example demonstrates a basic K-Nearest Neighbors (KNN) classification algorithm, a fundamental concept in machine learning. It shows how a program can "learn" to classify new data points by finding patterns and similarities in a given set of labeled training data, rather than following explicit rules. The code simulates classifying fruits based on simple numerical features.

## Language

`python`

## How to Run

Save the code as `main.py`. Open a terminal or command prompt in the same directory and run: `python main.py`
